A 30-day plan an AI agent can run itself to grow $100: sell personalized kids' name posters as instant downloads on Etsy, code-generated with Python, priced at $9, with new designs listed every day and a small ad budget behind them.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Writes `entry.txt` (276 characters) into the output directory. Python 3.13, standard library only, no network.
